### 新增
- **Agent 专属部件动作**：六个形象分别使用眼睛与爪腿、花瓣与提示符、立方体与箭头、四个星尖、像素内块和 Z 字笔画表演。工作、待审批、通过、拒绝、回合结束与休眠具有不同的姿态、动作方向和部件先后关系；小剧场调用各形象自己的动作并保留身份颜色。
- **动作对照调试页**：`?preview=agents` 支持逐个播放、状态切换、慢放、省电和统一颜色对照；`&view=states` 并排展示同一形象的工作、待审批、通过与拒绝，附 14px / 18px 实际尺寸预览。

### 改进
- **小图标辨识度**：收紧 14–20px 品牌图形的视框，减少装饰预留空间；中等尺寸平滑恢复留白。通过探头、招手、蓄力雀跃和回撤表达状态，Gemini 使用连续轮廓变形避免星尖拼接缝，并适配 macOS WebKit 的动作重启。
- **真实事件驱动动作**：主 Agent 工作状态跟随实时回合事件，子 Agent 工作与完成状态使用实际记录；重复事件只重启动作层，保持 SVG 与部件稳定。

### 修复
- **审批反馈归属与复位**：通过和拒绝反馈仅通知对应会话及该品牌的汇总标签，其他会话不再串联庆祝；新的待审批请求优先，反馈具有独立到期时间，失败的审批操作不触发成功动作。
- **省电与减弱动态效果**：暂停常驻循环时仍允许短反馈和界面入场完成；进入减弱动态效果时取消动作并恢复原形，恢复后不重播已取消的反馈，避免残留变形或图标停留在透明起点。
