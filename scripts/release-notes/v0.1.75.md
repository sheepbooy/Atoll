### 新增
- **Pi 接入**：在 `~/.pi/agent/extensions` 部署全局桥接扩展，通过 `tool_call` 拦截 bash / PowerShell / write / edit，审批卡与规则引擎和现有 Agent 共用；同步 Pi 会话、模型与 token 用量。Atoll 未运行时回落到 Pi 自带 TUI 确认，print/JSON 模式默认失败关闭；提供 `ATOLL_PI_FAIL_OPEN=1` 与 `ATOLL_PI_GATED_TOOLS` 环境变量。
- **Pi 形象**：使用官方珊瑚 / 蓝 / 黄三色拼块标，含完整待机、工作、通过、拒绝与休眠动作。

### 修复
- **Pi 回合状态与终端提示**：监听 Pi 的 `agent_end` 事件同步回合结束与累计用量，并使用 Pi 支持的 `hasUI` 判断显示终端状态；补充回归测试。
