### 改进
- **前端 App.tsx 拆分**：从 2,711 行缩到 1,048 行的 hook 编排壳——`renderPanel()` 变为 `IslandPanelRouter` 组件（agent 菜单列表一并迁入），430 行 header JSX 变为 `IslandHeader` + `ArtworkBackdrop`，岛面 chrome 标志收敛为纯函数 `deriveIslandChromeFlags()`；状态/处理簇按既有模式抽成 `useSnapshotStream`、`useSessionActions`、`usePricingData`、`useAppSettings`、`useCompactLayout`、`useUsageSummary`、`useStashTakeover`、`useImeSync`、`useNativePresentationSync` 九个 hooks，持久化设置的一次性水合移入 `useAppSettings` 且启动时序不变，并清理约 220 个失效导入。402 个前端测试原样通过，`tsc --noEmit` 干净
- **Rust lib.rs 拆分**：从 6,829 行缩到 370 行只留 `run()`——63 个内联 Tauri 命令迁入 `commands/{snapshot,requests,media,settings_cmds,clipboard,history,file_station,pricing,system}.rs`，经 `commands/mod.rs` 再导出、`generate_handler!` 注册表保持不变；快照组装移入新 `snapshot.rs`、时间戳助手移入 `local_time.rs`、zcode 会话与 rollout 路径助手移入 `transcript_cache.rs`、窗口几何/光标/缓动助手移入 `window.rs`、`build_hook_status` 移入 `session.rs`；11 个内联测试模块迁为根级 `#[cfg(test)]` 文件（`core_tests` 按域再拆为 window/session/transcript_cache/token_usage/hooks_asset/settings/tray/monitors 测试文件，共享 `test_app_state` 助手留在 `core_tests.rs` 兼容既有导入），`cargo test` 数量与拆分前一致（309）
- **样式表拆分**：9.5k 行 `styles.css` 变为按原顺序 `@import` 15 个分节文件（`src/styles/`）的 barrel，产物 CSS 与拆分前逐字节一致（比对过打包产物）；读 CSS 的测试改经 `test-utils/stylesSource.ts` 解析 barrel
- **动效时长单一来源**：JS 编排计时器与 CSS 动画共享的时长只在 TS 常量（`atollTransitions` / `islandPresentation`）里定义，`animationTiming.ts` 启动时把 `--atoll-enter-ms`、`--atoll-exit-ms`、`--reaction-*-ms`、`--duration-expand`、`--panel-exit-ms`、`--resolve-feedback-ms` 注入 `:root`，所有耦合 CSS 规则改引变量，删除 tokens.css 里三处重复 token 与"保持同步"注释；同步测试端到端校验变量接线（规则必须引用变量、注册值必须等于 TS 常量、jsdom 验证注入生效、耦合规则出现硬编码字面量即构建失败）
- **全局 prefers-reduced-motion**：以标准全局规则取代手工维护的约 80 行选择器清单（旧清单在 258 个 keyframes 里漏掉大多数）——所有动画/过渡压到 1ms、单次运行、保留 fill 末态，新动画组件自动覆盖；歌词变暗为唯一显式例外。`prefersReducedMotion()` 抽到 `animationTiming.ts` 并新增 `motionDelay()`，`useAtollPhase` / `useFileStation` 在减弱动效时把编排计时器快进到 0，与 CSS 降级及 Rust 侧窗口吸附对齐
