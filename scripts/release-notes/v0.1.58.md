### 新增
- **审批历史**：权限请求持久化到本地 SQLite（`~/.atoll/approval_history.db`），重启不丢；新增历史视图，支持关键词 / 会话 / Agent / 结果多维搜索筛选、逐行展开完整命令与项目信息，一键导出 JSON / CSV 到 `~/Downloads` 并可在文件夹中显示；记录覆盖批准、拒绝、超时、在别处处理等全部结局，保留策略 5000 条 / 90 天自动清理
- **全局快捷键**：Settings → Shortcuts 可配置系统级快捷键——召回浮岛（默认 `Cmd/Ctrl+Shift+Space`）、批准（`Cmd/Ctrl+Shift+Y`）、拒绝（`Cmd/Ctrl+Shift+N`），与通知互补（听到提示音 → 热键直接批）；内置按键录制器改键、总开关一键停用，热键被其他应用占用时行内红字提示；召唤为切换语义：按一下展开并保持，再按一下收回
- **Gemini CLI 适配**：`BeforeTool` 阻断式审批——Shell / 写文件 / 网络抓取等有副作用的工具先经 Atoll 批准才执行，拒绝时模型直接收到阻断原因；只读工具不弹卡不阻塞；Atoll 未运行时 fail-open 回落 Gemini 自带权限流；Settings → Agent hooks 一键安装 / 卸载（写 `~/.gemini/settings.json`，保留用户其他 hooks），hook 健康检测覆盖 Gemini；需 API key 认证（免费档 Google 登录已由官方迁移至 Antigravity）
- **Windows Now Playing + 滚动歌词**：Windows 上经 SMTC（系统媒体传输控制）读取当前曲目、封面与播放进度，支持播放 / 暂停 / 上一首 / 下一首；LRCLIB 滚动歌词管线同步可用，行为与 macOS 一致
- **通知中心提醒**：新权限请求的提醒模式可在 Settings → Notifications 切换——默认**强制打断**（浮岛自动展开并置前，行为不变）；新增**仅通知**模式，不打断当前工作，改为发送系统通知（标题含 Agent 名，正文含命令摘要与项目目录，跟随界面语言），点击通知、Dock 图标或浮岛本体即展开到审批卡片；模式持久化于 `~/.atoll/settings.json`（`approvalNoticeMode`）
