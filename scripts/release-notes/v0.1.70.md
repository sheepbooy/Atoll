### 新增
- **自动省电**：默认 10 秒无浮岛交互后暂停装饰循环、彩蛋计时与数字动画；悬停、快捷键召回、文件拖拽和新审批恢复反馈。设置 → 岛屿外观 → 动效与省电可选择「始终完整动效」，设置持久化，审批沿用原通知模式。
- **真实事件接入验证**：区分配置已安装、等待真实事件与连接已验证，仅认可验证开始后的新事件；60 秒超时提示检查步骤与重试，重装重置状态。Cursor 确认观察连接，权限请求另行标记；修正内置 Node 运行时提示，中英文同步。
- **Agent 小剧场**：真实生命周期触发码字、子 Agent 入队与离场、当前回合结束互动，按空间最多展示三个 SVG 角色及 `+N`。单次 2.4 秒，不回放历史、不积压、不自动展开，审批与拖拽优先，支持减弱动态效果。

### 优化
- 音乐、封面与歌词共享媒体状态：macOS 使用现有适配器 stream，断流退避重连并共享轮询兜底；Windows 合并现有 SMTC 采样。所有媒体功能关闭后停止平台采样。
- 歌词按曲目本地缓存，切歌用曲目代次丢弃陈旧查询结果；按歌词行边界刷新，隐藏进度不再推动整个浮岛更新，减少无变化快照刷新。
- 增加 macOS 固定场景 CPU 对照脚本，要求内嵌前端构建，检查 WebKit 进程归属及媒体就绪状态；[结果与适用范围](docs/energy-benchmark.md)。
