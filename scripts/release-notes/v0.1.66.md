### 新增
- **内置 Node.js 运行时**：全新电脑（未装系统 Node.js）上安装 agent hooks 不再报 "Node.js not found"——Atoll 现自带一份 Node 22.23.3 LTS（macOS arm64 / Windows x64），随安装包分发。hook 安装时解析 Node 的优先级不变（登录 shell → PATH → Windows 硬编码路径），全部落空才回退内置运行时（macOS 取 `Atoll.app/Contents/Resources/node/bin/node`，Windows 取 `<安装目录>/node/node.exe`），老用户行为与已写入的 hook 配置完全不受影响。运行时由 `scripts/fetch-node-runtime.mjs` 在 CI 构建时从 nodejs.org 下载并校验官方 SHASUMS256 后解出单二进制（重复构建按版本 + 校验和幂等跳过），`build.rs` 为跨平台资源条目写 0 字节占位保证任意平台可构建；`resolve_node_executable` 仅接受非空文件，占位永远不会被误判为可用。代价：macOS DMG 约增大 35–40MB、Windows MSI 约增大 20MB。背景：Claude Code 原生安装器已不依赖系统 Node，"新电脑装了 Claude Code 但没有 Node" 已是常见环境，此前的 Node 强依赖把这类用户挡在 hook 安装门外
