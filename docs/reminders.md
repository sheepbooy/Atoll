# 综合提醒（v0.1.71）

提醒无需连接 Agent。顶栏铃铛或 `Cmd/Ctrl+Alt+R` 打开面板，快捷键可在设置 → 快捷键修改。点击 5、15、25、60 分钟直接启动；输入时间和事项后，先看到准确触发时间，再按回车创建。中文输入法选词回车不会提交。快捷键创建成功后收回浮岛并归还焦点；鼠标创建后保留列表。

| 中文 | English | 结果 |
| --- | --- | --- |
| 20分钟后喝水 | in 20 minutes drink water | 倒计时 |
| 半小时 / 25m | 30 minutes / 25m | 无标题倒计时 |
| 明天下午3点开会 | tomorrow at 3pm meeting | 一次事件 |
| 18:30取快递 | 18:30 collect parcel | 下一次 18:30 |
| 每天晚上10点睡觉 | every day at 10pm sleep | 每天 |
| 工作日15点休息 | weekdays at 15:00 break | 周一至周五 |
| 每周五18点写周报 | every friday at 6pm report | 每周五 |
| 每隔45分钟站起来 | every 45 minutes stretch | 固定间隔 |

没有时间、不完整或明确过期的时间会提示错误并保留输入。也可使用「选择日期时间」表单。运行中的倒计时可暂停、继续；事件可编辑和删除；重复规则可暂停、恢复。待处理卡片提供完成、延后 5 / 15 分钟，倒计时还可沿用原时长重新开始。完成或延后当前实例不改变重复规则的未来时间表。

默认到期发送一次系统通知和声音，在浮岛中显示 8 秒提醒卡片，不主动获取键盘焦点。悬停或操作后保持展开。审批、文件拖拽、文本输入优先，安全后再展示。提醒面板底部可独立关闭声音或选择「仅通知」。系统通知只负责提示，处理按钮位于浮岛内。

需保持 Atoll 运行；面板内有开机自启动设置入口。完全退出后不会在后台提醒，再启动集中补报。数据保存在 `~/.atoll/reminders.db`，独立于审批历史，全程本地运行。已完成实例保留 30 天，待处理实例不会自动过期。

## 实现约定

- Rust 调度与 SQLite 事务先保存再发事件。持久化版本号防止旧 IPC 返回覆盖较新的调度结果，实例的 `alerted` 标记防止重连、重启重复提示。
- 倒计时、间隔按截止时刻计算，睡眠期间继续经过；暂停倒计时保存剩余秒数。日历重复按系统当地时间计算，一次事件保存确定的触发时刻。
- 重启、唤醒每条重复规则最多补报一次，推进到未来。夏令时缺失时间顺延到第一个可用分钟，重复小时只选择最早一次。
- 无未来截止时刻时使用条件变量无限等待状态变化；有提醒按最近到期时间等待，最长每 30 秒校准。前端只更新正在显示的倒计时标签。
- 数据写入失败保留输入并显示错误。系统通知发送报错时用应用内短提示音降级，仍保留待处理卡片。

## 验证与复现

```sh
# Node 26 的实验性 Web Storage 会干扰 jsdom；关闭该开关后执行测试。
NODE_OPTIONS=--no-experimental-webstorage npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo check --manifest-path src-tauri/Cargo.toml --target x86_64-pc-windows-gnu --lib
# 本地调试包不生成需要发布私钥的更新器签名。
npm run tauri build -- --debug --bundles app --config '{"bundle":{"createUpdaterArtifacts":false}}'
```

自动化覆盖中英文解析、跨天、过期/歧义、时区与夏令时、暂停恢复、重复补报、延后、批量到期、SQLite 事务失败、保留期限、空闲调度无轮询、IME、旧响应去重、草稿保留、审批/拖拽/输入优先级及卡片超时恢复。浏览器检查了快速创建和日期时间表单。隔离 macOS 调试包使用专用数据库验证了实际调度、启动补报、间隔推进、重启去重。

仍需在正式 macOS / Windows 安装包上人工验收系统通知与声音、前台应用焦点、真实睡眠唤醒、物理刘海及多显示器表现。Windows 交叉编译通过不等于 Windows 安装包实机验收。
