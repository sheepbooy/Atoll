# 自动省电、接入验证与 Agent 小剧场

本轮三项功能已落地到代码。默认自动省电；设置中可选始终完整动效。未发布新版本，也未替换已安装的 Atoll。

## CPU 对照结果

2026-10-02，在 Mac17,9、macOS 27.0.1 上测试内嵌前端的 release 构建。每组预热 30 秒，采样 60 秒。两种模式均使用本轮代码，分别为 `full` 和 `auto`，窗口折叠、鼠标在浮岛之外。

| 固定场景 | 完整动效平均 CPU | 自动省电平均 CPU | 下降 |
| --- | ---: | ---: | ---: |
| 无会话，媒体功能关闭 | 0.893% | 0.302% | 66.2% |
| 一个 Agent 工作会话，媒体功能关闭 | 3.888% | 0.367% | 90.6% |
| 音乐播放，歌词启用，刘海屏折叠态 | 0.818% | 0.318% | 61.1% |

CPU 合计包括主进程与归属于该进程的 WebKit 进程；100% 表示一个 CPU 核心。音乐场景的 Perl 媒体适配器另计，两种模式均为 0.075%。播放器自身的 CPU 不属于 Atoll。

这些受控场景达到工作场景下降至少 50%、纯空闲低于 2% 的目标，不能直接推算瓦数或电池续航。

[原始采样数据](energy-benchmark.json) 保存每组的进程平均值、合计平均值和范围。`meanCpuPercent` 不包含适配器；`processMeans` 则包含脚本采样的所有进程。

## 方法与适用范围

- 基准脚本复制构建产物到临时 `.app`，使用独立标识启动，通过 macOS responsibility API 确认 WebKit 归属。采样结束只关闭该实例及其媒体适配器。
- 以 `top` 每秒采样，丢弃首个累计值；进程归属不完整、提前退出或音乐与匹配歌词未就绪时拒绝结果。采样期间没有构建或测试负载。
- 工作场景固定一个 Codex 会话状态，未发送真实工具流量；小剧场没有在采样期间触发。这测量折叠展示的常驻开销。
- 基准模式关闭 Hook 服务、后台归档与持久化、价格刷新、蓝牙及剪贴板监控，避免修改现有配置、接管现有 Hook 或混入后台维护负载。真实生产任务的整体 CPU 仍需另行复测。
- 音乐场景使用独立临时 Chrome 播放本地静音音频，通过真实系统媒体接口读取；使用隔离的本地歌词缓存，不切换用户播放器或查询在线歌词。媒体与歌词都已就绪，但现有布局在刘海屏折叠态不显示歌词，因此该行不代表外接无刘海屏上可见歌词的渲染耗费。
- 之前安装的 v0.1.69 曾测得约 32.4%–34.2% 合计 CPU，当时有会话活动、采样条件不同，不能与本表直接相减得出版本收益。
- 最初的探索采样使用 release 优化却仍从开发服务器加载前端，已经排除。正式基准要求 `tauri/custom-protocol`；基准入口会拒绝开发模式。

复测需先构建：

```sh
npm run build
cargo build --release --features tauri/custom-protocol --manifest-path src-tauri/Cargo.toml
python3 scripts/benchmark-energy.py --scenes idle working --output /private/tmp/atoll-energy.json
```

音乐场景需先开始系统可识别的播放，再运行 `--scenes media`；可用 `--lyrics-cache-dir` 指定隔离缓存。所有模式默认预热 30 秒、采样 60 秒。此次完整六组采用 `--scenes idle working media`。

## 实现行为

- **省电：** 持久化 `energyMode: auto | full`，旧配置默认 `auto`。10 秒无浮岛交互后停止装饰循环、吉祥物彩蛋计时与数字动画；悬停、召回、拖拽和新审批恢复反馈，审批通知策略沿用原设置。计数和状态继续更新，数字时钟只在计数器内刷新。
- **媒体：** macOS 首次完整读取后使用现有适配器 stream，断流按 1、2、4、8、16、最多 30 秒退避重连；共享轮询兜底为播放 1 秒、暂停或无媒体 5 秒。Windows 合并既有 SMTC 读取。所有媒体消费者关闭后停止平台采样；隐藏进度不推动整个浮岛更新。歌词按曲目缓存在本地，查询采用曲目代次校验，包含 A→B→A 快速切换。
- **验证：** 配置安装与实际连接分开呈现。仅桥接校验通过且被正常处理的真实事件更新证据；点击后只认可该次验证开始之后的事件，60 秒无事件展示检查步骤与重试。重装清空验证代次；Cursor 标记观察连接，权限请求单独确认。不会自动启动 Agent 或执行命令。
- **小剧场：** 统一生命周期事件携带事件 ID、Agent、会话、可选子 Agent、类型与时间；只映射现有接入实际支持的事件。复用 SVG 吉祥物展示码字、挥手入队、离场与「本轮结束」，最多三个角色及 `+N`。新事件替换旧场景，2.4 秒结束，不回放历史、不积压队列、不主动展开；审批与拖拽优先，减弱动态效果时展示静态结果。

测试涵盖媒体流格式与错误、退避上限、消费者关闭、暂停与拖动、快速切歌和陈旧结果、验证超时／重装／错误 Agent、生命周期去重、审批与拖拽抢占，以及现有窗口布局、刘海空间与快捷键行为。

浏览器测量不包含原生鼠标采样与 WebKit 事件传递。本轮未测定原生端到端悬停延迟和审批延迟，也未完成真实外接多屏切换、文件投喂的原生手动回归及 Windows 实机验收；这些不应标记为已通过。CPU 对照达到的是上述固定夹具的目标。
