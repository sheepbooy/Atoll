03 / BETTER TOGETHER

你的 Agent，
熟悉的工作方式。

在应用内安装对应 Hook，即可接入。
每个 Agent 的支持能力，都清楚写在这里。

Claude Code（CLI + Desktop）

Settings → Agent hooks → Install。支持权限审批、Plan 模式与 subagent 追踪；Desktop 需选 Ask permissions，安装后完全退出并重启。

Codex（CLI + Desktop）

Settings → Agent hooks → Install Codex。支持 CLI / Desktop 会话识别、权限审批、subagent 事件与 transcript 详情；安装后在 /hooks 信任 Atoll hook。

Cursor（IDE Agent）

Settings → Agent hooks → Install Cursor。通过 observer hooks 追踪 Agent / Ask 会话、subagent 与 Token；Shell 权限仍由 Cursor 自带 UI 处理。

ZCode（CLI + Desktop）

Settings → Agent hooks → Install ZCode。支持权限审批、会话与 Token 用量统计（读取 rollout JSONL，含子代理归集）。

Gemini CLI（API key 用户）

Settings → Agent hooks → Install Gemini。BeforeTool 阻断式审批，仅拦有副作用的工具；安装后在 Gemini 中 /hooks 信任 Atoll hook。

OpenCode

Settings → Agent hooks → Install OpenCode。OpenCode 没有 hooks 配置文件——Atoll 在其插件目录部署进程内桥接插件；Atoll 不在线时 OpenCode 自带确认自动兜底。

04 / MAKE IT YOURS

给顶栏，
一个新的住客。

下一次 Agent 需要你，浮岛就在那里。

从 Releases 手动下载

推荐 — 一行命令

在终端中运行以下命令，自动下载并安装最新版 Atoll。

curl -fsSL https://raw.githubusercontent.com/sheepbooy/Atoll/main/scripts/install.sh | bash
brew tap sheepbooy/tap && brew install --cask --no-quarantine atoll

应用尚未公证。首次启动若被拦截，在 Applications 中右键「打开」一次即可。也可从 Releases 下载 DMG 手动安装。

推荐 — PowerShell 一行安装

在 cmd、PowerShell 或 Windows 终端中运行：

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/sheepbooy/Atoll/main/scripts/install.ps1 | iex"

首次运行若被 SmartScreen 拦截，选择「更多信息」→「仍要运行」。Hook 安装优先使用本机 Node.js，系统没有 Node 时自动回退应用内置运行时。也可从 Releases 下载 MSI 手动安装。
